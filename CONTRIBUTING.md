# Contributing to LeadHunting AI

Thank you for your interest in contributing to LeadHunting AI!

## Getting Started

1. Visit [leadhunting.app](https://leadhunting.app) to see the platform in action
2. Fork the repository
3. Create a feature branch
4. Make your changes
5. Submit a pull request
