# LeadHunting AI

> AI-Powered Real Estate Lead Generation Platform

🌐 **Website:** [leadhunting.app](https://leadhunting.app)

## Overview

LeadHunting AI is an autonomous 24/7 AI concierge for real estate agents. It captures, qualifies, and nurtures leads using AI-powered chatbots, lead funnels, and smart analytics.

## Features

- 🤖 **Autonomous Content Pipeline** — Auto-generates blog posts, images, audio, video using Google AI Studio (free tier)
- 📊 **Smart Lead Scoring** — AI-powered lead qualification with behavioral tracking
- 📧 **Multi-Platform Auto-Posting** — Publishes to LinkedIn, Twitter, Facebook with policy compliance
- 💳 **Credit Billing System** — 500%+ margin on AI tools (admin uses $0 free tier)
- 🏠 **Real Estate Funnel Builder** — Buyer, seller, investor, CMA, tenant funnels
- 📱 **PWA** — Installable on mobile, offline-capable
- 🔒 **Compliance Engine** — CAN-SPAM, TCPA, GDPR, platform policies enforced

## Tech Stack

- **Frontend:** Next.js 16, React 18, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** Prisma ORM, Supabase PostgreSQL
- **AI:** Google AI Studio (Gemini Flash, Imagen 3, Veo 2, TTS)
- **Payments:** Stripe (dynamic pricing via price_data)
- **Deployment:** Vercel (free Hobby plan)
