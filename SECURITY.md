# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to: security@leadhunting.app

## Security Measures

LeadHunting AI implements:
- JWT session authentication with session invalidation
- Rate limiting on all auth endpoints
- CSP headers (no unsafe-eval)
- COOP/COEP/CORP headers
- GDPR/TCPA/CAN-SPAM compliance
- Encrypted credential storage
